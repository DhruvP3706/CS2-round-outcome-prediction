# Publication tables

The required tables are split between the compact descriptive CSVs in this
directory and the directly generated result exports:

1. `dataset_description.csv`
2. `split_description.csv`
3. `class_distribution.csv`
4. `feature_families.csv`
5. `model_configurations.csv`
6. `performance_by_time.csv`
7. `performance_by_time.csv` (cutoff-level model comparison)
8. `matched_cohort.csv`
9. `../statistics/confidence_intervals.csv` and `../statistics/paired_tests.csv`
10. `map_wise_performance.csv`
11. `feature_ablation.csv`
12. `fifth_sample_holdout.csv`
13. `previous_research_comparison.csv`

Rows are generated from saved artifacts or explicitly mark unavailable
evidence. No manually edited test score is used as a model-selection result.
